它能做什么

你只管看，对齐交给它。

进度自动对齐

房主拖动进度条时，成员端同步跳转，误差通常在 0.3 秒以内。

12:34

播放暂停跟随

房主暂停，成员端同步暂停；房主播放，成员端同步继续。

跨站看同一内容

页面地址不同也能一起看，点「强制同步」即按房主的进度播放。

一键跳转至相同视频

点面板上的「跳转到一起看的视频」，自动在新标签打开房主的视频页并开始同步。

房间码即邀请

创建房间得到 4 位码，发给朋友输入即可加入。

缓冲时全房间等待

有人缓冲时全房间自动暂停等待，房主也可以点「不等了，继续播放」。

从安装到开看 · 只需几分钟

五步，开始一起看。

  1. 安装油猴（Tampermonkey）

    油猴是浏览器的脚本管理器，本脚本需要它运行。右侧商店和官网任选其一。

    Chrome 商店在国内常无法访问，可改用 Edge 或 Firefox 的商店，或在商店中搜索 Tampermonkey。

    Chrome 商店↗ Edge 加载项↗ Firefox 附加组件↗ 油猴官网↗

  2. 安装脚本

    点击页面顶部的「一键安装脚本」，按提示完成安装。若浏览器未弹出安装页，改为点击「复制脚本代码」，再到油猴管理面板新建脚本并粘贴内容。

    // ==UserScript==
// @name     一起看 · 视频同步
// @version  {{VERSION}}
// @author   IYIAK
// ==/UserScript==

  3. 视频页点击悬浮球，创建房间

    打开具体的视频播放页，点击右下角悬浮球，填写昵称后点击「创建房间」，得到一个 4 位房间码。

    可以在设置中关闭悬浮球

    一起看

  4. 把房间码发给朋友

    把创建出的 4 位房间码发给朋友，之后由房主控制进度，所有人自动对齐。

    72K9
    阿凯 12:34
    小林 12:34

  5. 朋友加入房间

    朋友在任意页面点击油猴菜单中的「开始一起看」，展开面板后输入房间码并点击「加入」。没有视频也能加入，加入后可跳转到房主的视频。

    也可以在任意视频页点击悬浮球加入房间，并支持跳转至同一视频

遇到问题时

常见问题

提示「连不上同步服务」怎么办

多数情况是网络原因：开启代理后重试；或参照安装教程的附录，自行搭建后端并替换地址。

右下角没有圆形按钮怎么办

打开具体视频页并等待播放器被检测；如果是要加入房间，可直接从油猴菜单点击「开始一起看」，没有视频也能打开面板。

如何彻底移除

打开油猴管理面板，删除「一起看 · 视频同步」这一行，页面随即恢复原样。
