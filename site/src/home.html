它能做什么

你只管看，对齐交给它。

进度自动对齐

房主拖动进度条时，成员端同步跳转，误差通常在 0.3 秒以内。

12:34

播放暂停跟随

房主暂停，成员端同步暂停；房主播放，成员端同步继续。

跨站看同一内容

页面地址不同也能一起看，点「强制同步」即按房主的进度播放。

一键跳转至相同视频

点面板上的「跳转到一起看的视频」，自动在新标签打开房主的视频页并匹配该站点。

房间码即邀请

创建房间得到 4 位码，发给朋友输入即可加入。

缓冲时全房间等待

有人缓冲时全房间自动暂停等待，房主也可以点「不等了，继续播放」。

从安装到开看 · 只需几分钟

六步，开始一起看。

  1. 安装油猴（Tampermonkey）

    油猴是浏览器的脚本管理器，本脚本需要它运行。右侧商店和官网任选其一。

    Chrome 商店在国内常无法访问，可改用 Edge 或 Firefox 的商店，或在商店中搜索 Tampermonkey。

    Chrome 商店↗ Edge 加载项↗ Firefox 附加组件↗ 油猴官网↗

  2. 安装脚本

    点击页面顶部的「一键安装脚本」，按提示完成安装。若浏览器未弹出安装页，改为点击「复制脚本代码」，再到油猴管理面板新建脚本并粘贴内容。

    // ==UserScript==
// @name     一起看 · 视频同步
// @version  {{VERSION}}
// @author   IYIAK
// ==/UserScript==

  3. 在视频网站匹配域名

    点击浏览器右上角的油猴图标，选择「匹配当前域名」。匹配后脚本才会在该网站生效。

    若找不到油猴图标，可能收在右上角的拼图（扩展程序）图标里，点开即可看到。

    www.bilibili.com
    一起看 · 视频同步
    匹配当前域名（www.bilibili.com）
    匹配上级域名（bilibili.com，含所有子域）
    查看已匹配域名

  4. 呼出面板

    需要时，点击浏览器右上角的油猴图标，在菜单里点「打开一起看」，面板即出现在页面上。

    未进入房间时，页面右下角不显示圆形按钮，需要通过这个菜单打开面板；进房间后点圆形按钮即可随时唤出。

    www.bilibili.com
    一起看 · 视频同步
    打开一起看
    离开房间
    查看已匹配域名

  5. 填写昵称，创建房间

    在面板里填写昵称后点击「创建房间」，得到一个 4 位房间码。

    一起看

  6. 把房间码发给朋友

    对方装好同一份脚本后，在视频页输入房间码即可加入；之后由房主控制进度，所有人自动对齐。

遇到问题时

常见问题

提示「连不上同步服务」怎么办

多数情况是网络原因：开启代理后重试；或参照安装教程的附录，自行搭建后端并替换地址。

右下角没有圆形按钮怎么办

多数情况是尚未在该网站完成「匹配」（油猴菜单中点击「匹配当前域名」）；未进入房间时页面也不显示圆形按钮。

如何彻底移除

打开油猴管理面板，删除「一起看 · 视频同步」这一行，页面随即恢复原样。
