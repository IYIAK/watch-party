# 一起看 · 视频同步 —— 新手安装教程

> 你现在看到的这个页面就是**安装页** —— 直接点上面的 **「一键安装脚本」** 就能装好；本页就是它的详细说明。
>
> 这个工具能做什么：**你和朋友在不同地方，看同一个视频，进度自动对齐。**
> 房主按暂停，你这边也暂停；房主拖进度条，你这边跟着跳；谁的网络卡了，大家一起等他。
>
> 全程大约 10 分钟，**不需要懂编程**。照着一步步做就行。

---

## 开始之前

| 你需要 | 说明 |
| --- | --- |
| 一台电脑 | Windows / Mac 都行 |
| Chrome 或 Edge 浏览器 | Firefox 也可以（步骤里括号里会写差异） |
| 10 分钟 | 慢的话 20 分钟 |

**关于"服务器"**：这个工具需要一个"同步服务器"来传递进度。**它已经搭好了**，地址已经写在脚本里，**你不用自己搭** ✅
（如果你以后想自己搭一个，见文末的[附录](#附录自己搭一个后端可选)；不想读也可以完全跳过。）

**关于"匹配域名"**：脚本会被装在所有网站上，但**只在你"匹配"过的网站上生效**。
这样它就不会在你逛淘宝、看新闻的时候冒出来打扰你。第三步会教你怎么匹配。

---

## 第一步：装 Tampermonkey（大家叫它"油猴"）

油猴是浏览器的"插件管理器"，我们的脚本要靠它运行。

1. 打开下面的任意一个（选你能打开的那个）：
   - Chrome：网上搜 `Tampermonkey Chrome 商店`，或直接打开 `https://chromewebstore.google.com/` 搜 **Tampermonkey**
   - Edge：打开 `https://microsoftedge.microsoft.com/addons/` 搜 **Tampermonkey**
   - Firefox：打开 `https://addons.mozilla.org/` 搜 **Tampermonkey**
2. 点 **「添加到 Chrome / 获取 / 添加到 Edge」** → 弹出确认框点 **「添加扩展程序」**
3. 装好后，浏览器**右上角**会出现一个图标。
   Chrome 里可能藏在"拼图"图标里面，点拼图 → 找到 Tampermonkey → 点它右边的**图钉**，让它一直显示出来。

**✅ 怎么确认装好了**：点右上角那个新图标，能看到一个英文菜单（Dashboard / …）就对了。

---

## 第二步：安装脚本

打开安装页 —— 也就是你现在正看着的这一页（自己部署的话，就是那个网址）：

1. 点 **「一键安装脚本」** → 跳到 Tampermonkey 的安装页 → 点 **「安装」** 就完事了 ✅
2. 如果点了没反应（例如没装油猴、或浏览器不支持），改用下面的手动方式：
   - 在安装页点 **「复制脚本代码」**（代码已经复制到剪贴板）
   - 点浏览器右上角的 **Tampermonkey 图标** → 选 **「管理面板 / Dashboard」** → 点上面那排的 **「＋」**（新建脚本）
   - 编辑器里会有一段示例代码，**全部删掉**（`Ctrl + A` 再 `Delete`），然后**粘贴**（`Ctrl + V`）
   - 按 **`Ctrl + S`** 保存

**✅ 怎么确认装好了**：Tampermonkey 管理面板里能看到一行「一起看 · 视频同步」，前面是绿色的开关。

> **可能弹出一个权限询问**（比如"是否允许此脚本访问 xxx"）→ 选 **「总是允许」**。
> 脚本需要连同步服务器，不允许的话就同步不了。

> 想邀请朋友？在安装页点 **「复制安装地址」**，把复制到的链接发给他，他点开就能装 ✅

---

## 第三步：在你看视频的网站上"匹配"一下

1. 打开你看视频的网站，停在**具体的视频播放页**（比如 B 站的某个视频页）。
2. 点浏览器右上角的 **Tampermonkey 图标** → 点 **「匹配当前域名（www.xxx.com）」**。
3. 页面**右下角**会出现一个**圆形小按钮**。

**✅ 怎么确认成功了**：能看到那个圆钮。

> 换个网站看？在那个网站上**重复这一步**即可。
> 菜单里还有 **「查看已匹配域名」**（看都匹配了哪些）和 **「取消匹配当前域名」**（反悔）✅

**还没匹配的网站上，脚本是完全静默的**：不显示任何东西、也不发任何请求 ✅

---

## 第四步：和朋友一起看

### 如果你是"发起的人"（房主）

1. 点右下角**圆钮** → 打开面板。
2. 填一个昵称 → 点 **「创建房间」**。
3. 得到一个 **6 位房间码**（比如 `HT296M`）→ 点 **「复制」** 发给朋友。
4. 正常播放就行：**你按暂停、拖进度条，朋友那边都会跟着** ✅
   - 你拖进度条后，你这边会冒出一个气泡「已更新进度，成员将会同步」，朋友那边会显示「房主调整了进度」✅

### 如果你是"被邀请的人"（成员）

1. 装好**同一份脚本**（后端地址是同一个，所以能连同一个房间）✅
2. 点圆钮 → 在「房间码」里输入房主给你的 6 位码 → 点 **「加入」**。
3. 如果你看的**不是房主那个视频页**，面板上会出现一条提示：
   「你和大家不在同一个视频」+ 一个 **「跳转到一起看的视频」** 按钮
   → **点它**，会自动新开一个标签直达房主的视频，**旧标签会自动让位** ✅
4. 如果你俩是在**不同网站看同一部番**（页面地址不一样、但内容其实是同一个）：
   → 点 **「强制同步」**，就会照常按房主的进度走 ✅
   （这时提示会变成「已强制同步」，想取消就点「取消强制同步」）

### 面板里的两个开关（默认都开着）

- **自动跟随房主进度**：你比房主差超过 **2 秒**，自动跳过去。
- **跟随房主播放/暂停**：房主按播放暂停，你也跟着。
- 你自己拖过进度条后，**10 秒内不会被拽回来** ✅
  同时会**问房主**"要不要让全房间跳到你这里"（房主点「跟随 TA」就全房间一起跳；点「忽略」就什么也不发生）。
- 房主可以勾选 **「自动接受成员拖动」**：信任的房间里就不用每次问。

### 关于"气泡提示"

面板收起（或全屏）的时候，重要的事情会用**右下角的小气泡**提醒你（全屏时移到右上角），气泡上直接带按钮，点一下就能处理 ✅
比如：等待某某缓冲… / 某某想跳到 12:34 / 你和大家不在同一个视频。

> 如果你已经把面板展开了，那就不用气泡了 —— 那些按钮在面板里本来就有，气泡再来一份只会重复、还会挡住面板。纯文字的提醒（比如"连不上同步服务"）还是会照常弹出来。

## 常见问题

**① 面板提示「连不上同步服务（检查网络/代理）」**
说明浏览器连不上同步服务器（地址写在脚本顶部，自建后端的见文末附录）。多数是网络原因，不是脚本坏了。
- 有代理/加速工具 → 打开它，脚本会自动走系统代理 ✅
- 没有 → 先试试刷新页面；还不行就见文末[附录](#附录自己搭一个后端可选)，自己搭一个换成别的地址就通了。

**② 右下角没有圆钮？**
- 多半是**还没在这个网站上"匹配"**（回到第三步）。
- 另外：**还没进房间的时候，页面上本来就没有圆钮** ✅ —— 这时从 **Tampermonkey 菜单 →「打开一起看」** 呼出面板。
- 实在不行：刷新一下页面。

**③ 提示「已在另一个标签同步」？**
正常的 ✅ —— 同一个浏览器里**只有一个标签在同步**（避免两个标签互相打架）。
想让**当前**这个标签接管 → 在那个标签的面板里点 **「在此标签同步」**。

**④ 面板里看不到成员 / 数据不动？**
等几秒 ✅ —— 待机标签每 5 秒同步一次成员列表。

**⑤ 我和朋友差一点进度？**
正常误差在 **0.3 秒**以内 ✅。如果房主网络卡住（缓冲），大家会自动一起暂停等待，房主可以点「**不等了，继续播放**」继续。

**⑥ 全屏的时候看不到提示？**
全屏时只保留右上角的**气泡提示** ✅。
如果某个网站是把播放器本身（`<video>`）全屏，浏览器不允许任何东西浮在上面，这就没办法了（浏览器限制）。

**⑦ 想彻底不要了？**
Tampermonkey 管理面板 → 删掉「一起看 · 视频同步」这一行 → 页面立刻恢复原样 ✅

**⑧ 朋友也需要装吗？**
需要 ✅。在安装页点 **「复制安装地址」**，把链接发给他，他点开装一下即可。
后端地址已经写在脚本里，你们会自动连到同一个服务器、同一个房间。

## 附录：自己搭一个后端（可选）

> 什么时候需要：你想完全自己掌控，或者上面的"连不上同步服务"你没法用代理解决。
> 需要一点点命令行基础，**不会也不影响使用**。

1. 装 **Node.js 22 或更高**：`https://nodejs.org/`（一路"下一步"）
2. 打开命令行（Windows 搜"PowerShell"）：
   ```bash
   npm install -g wrangler
   wrangler login
   ```
   浏览器会弹出 Cloudflare 登录页，登录并授权。
3. 在本项目目录里：
   ```bash
   cd worker
   cp wrangler.toml.example wrangler.toml
   wrangler d1 create watch_party
   ```
   把屏幕上打印的 `database_id = "..."` 整行，填进刚生成的 `wrangler.toml`。
4. 建表并部署：
   ```bash
   wrangler d1 execute watch_party --remote --file=./schema.sql
   wrangler deploy
   ```
   最后一行会打印你的地址，形如 `https://xxxx.workers.dev`。
5. 回到脚本（Tampermonkey 里那一份），找到顶部的这两处：
   ```js
   // @connect      your-worker.example.workers.dev
   ```
   ```js
   workerUrlRemote: "https://your-worker.example.workers.dev",
   ```
   都换成你第 4 步拿到的地址（`@connect` 那里只填主机名，不带 `https://`），`Ctrl + S` 保存。

> ⚠️ **房主和成员必须使用同一个后端地址的脚本**，否则你们连的不是同一个房间。
> 更详细的英文步骤见 `docs/SETUP.md`。

## 一页速查

```
装油猴 → 粘贴脚本(Ctrl+S) → 在视频网站点"匹配当前域名" → 圆钮出现
房主：创建房间 → 把房间码发出去
成员：加入 → 视频不一样就点"跳转到一起看的视频"（跨站同内容点"强制同步"）
卡住：大家一起暂停等待，房主可点"不等了"
连不上：开代理，或自己搭后端
不要了：Tampermonkey 里删脚本
```
