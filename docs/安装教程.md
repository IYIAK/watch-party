# 一起看 · 视频同步 —— 新手安装教程

> 当前页面即**安装页**：点击页面上方的 **「一键安装脚本」** 即可完成安装，本页为详细说明。
>
> 功能说明：**与朋友身处不同地方，也能观看同一个视频，播放进度自动对齐。**
> 房主暂停时，成员端同步暂停；房主拖动进度条时，成员端同步跳转；有人网络卡顿时，全房间一起等待。
>
> 全程约需 10 分钟，**无需编程基础**，按以下步骤依次操作即可。

---

## 开始之前

| 你需要 | 说明 |
| --- | --- |
| 一台电脑 | Windows 或 Mac 均可 |
| Chrome 或 Edge 浏览器 | Firefox 也可（步骤中以括号标注差异） |
| 10 分钟 | 网络较慢时约 20 分钟 |

**关于"服务器"**：本工具需要一个同步服务器来传递播放进度。**该服务器已经部署完成**，地址已写入脚本，**无需自行搭建**。
如需自行搭建，参见文末的[附录](#附录自己搭一个后端可选)，不需要的读者可跳过该节。

**关于"匹配域名"**：脚本会安装到所有网站，但**仅在已"匹配"的网站上生效**，
因此不会在浏览其他页面时出现。第三步将说明匹配方法。

---

## 第一步：安装油猴（Tampermonkey）

油猴（Tampermonkey）是浏览器的脚本管理器，本脚本需通过它运行。

1. 打开下列任一商店（选择可正常访问的一个）：
   - Chrome：网上搜索 `Tampermonkey Chrome 商店`，或直接打开 `https://chromewebstore.google.com/` 搜索 **Tampermonkey**
   - Edge：打开 `https://microsoftedge.microsoft.com/addons/` 搜索 **Tampermonkey**
   - Firefox：打开 `https://addons.mozilla.org/` 搜索 **Tampermonkey**
2. 点击 **「添加到 Chrome / 获取 / 添加到 Edge」**，在弹出的确认框中点击 **「添加扩展程序」**
3. 安装完成后，浏览器**右上角**会出现一个图标。
   在 Chrome 中该图标可能位于"拼图"图标内：点击拼图 → 找到 Tampermonkey → 点击其右侧的**图钉**，使其始终显示。

**确认安装成功**：点击右上角的新图标，若能看到英文菜单（Dashboard / …）即为正常。

---

## 第二步：安装脚本

打开安装页（即当前页面；自行部署时为对应的网址）：

1. 点击 **「一键安装脚本」** → 跳转到 Tampermonkey 的安装页 → 点击 **「安装」**
2. 若点击后无反应（例如尚未安装油猴，或浏览器不支持），改用手动方式：
   - 在安装页点击 **「复制脚本代码」**，代码已复制到剪贴板
   - 点击浏览器右上角的 **Tampermonkey 图标** → 选择 **「管理面板 / Dashboard」** → 点击上方的 **「＋」**（新建脚本）
   - 编辑器中会有一段示例代码，**全部删除**（`Ctrl + A` 后按 `Delete`），再**粘贴**（`Ctrl + V`）
   - 按 **`Ctrl + S`** 保存

**确认安装成功**：Tampermonkey 管理面板中可见「一起看 · 视频同步」一行，其前方为绿色开关。

> **系统可能会询问权限**（例如"是否允许此脚本访问 xxx"），请选择 **「总是允许」**。
> 脚本需要连接同步服务器，未授权则无法同步。

> 邀请朋友时，在安装页点击 **「复制安装地址」**，将复制的链接发给对方，对方打开即可安装。

---

## 第三步：在视频网站上"匹配"域名

1. 打开目标视频网站，并停留在**具体的视频播放页**（例如 B 站的某个视频页）。
2. 点击浏览器右上角的 **Tampermonkey 图标** → 点击 **「匹配当前域名（www.xxx.com）」**。
3. 页面**右下角**会出现一个**圆形按钮**。

**确认匹配成功**：页面上出现该圆形按钮。

> 在其他网站观看时，在该网站上**重复本步骤**即可。
> 菜单中另有 **「查看已匹配域名」**（查看已匹配的网站）与 **「取消匹配当前域名」**（撤销匹配）。

**在未匹配的网站上，脚本保持完全静默**：不显示任何内容，也不发送任何请求。

---

## 第四步：和朋友一起看

### 房主（发起的一方）

1. 点击右下角**圆形按钮**，打开面板。
2. 填写昵称 → 点击 **「创建房间」**。
3. 获得一个 **6 位房间码**（例如 `HT296M`）→ 点击 **「复制」** 并发送给成员。
4. 正常播放即可：**房主暂停或拖动进度条时，成员端都会同步跟随**。
   - 房主拖动进度条后，房主端出现气泡「已更新进度，成员将会同步」，成员端显示「房主调整了进度」。

### 成员（被邀请的一方）

1. 安装**同一份脚本**（后端地址相同，因此连接同一个房间）。
2. 点击圆形按钮 → 在「房间码」中输入房主提供的 6 位码 → 点击 **「加入」**。
   > **加入**仅代表进入房间，**不会**自动开始同步；同步哪个标签页由你自己决定（见下）。
3. 加入后，面板会提示「同步正在另一个标签进行」，并显示 **「同步当前视频」** 按钮：
   - 若观看的**就是房主的视频**：点击 **「同步当前视频」** 即开始同步
   - 若观看的**不是房主的视频**：面板会显示「你和大家不在同一个视频」与 **「跳转到一起看的视频」**
     → **点击该按钮**，会自动新开一个标签页直达房主的视频，**该标签页立即开始同步**，
     原标签页自动停止同步。标签页的规则如下：未经点击的标签页永远不会自行开始同步。
4. 若两人在**不同网站观看同一部番剧**（页面地址不同、内容相同）：
   → 点击 **「强制同步」**，即可按房主的进度继续。
   此时提示会变为「已强制同步」，需要取消时点击「取消强制同步」。

### 面板中的两个开关（默认开启）

- **自动跟随房主进度**：与房主的进度相差超过 **2 秒** 时，自动跳转对齐。
- **跟随房主播放/暂停**：房主播放或暂停时，成员端同步执行。
- 成员自行拖动进度条后，**10 秒内不会被拉回**。
  同时会**询问房主**是否让全房间跳转到该进度（房主点击「跟随 TA」则全房间跳转；点击「忽略」则不发生任何变化）。
- 房主可以勾选 **「自动接受成员拖动」**：在信任的房间中无需每次询问。

### 关于气泡提示

面板收起或全屏时，重要提示会以**右下角的小气泡**显示（全屏时位于右上角）；气泡自带按钮，点击即可处理。
例如：等待某某缓冲… / 某某请求跳转至 12:34 / 你和大家不在同一个视频。

> 面板已展开时无需气泡提示 —— 相关按钮在面板中已有，重复显示既冗余也会遮挡面板。纯文字提示（例如"连不上同步服务"）仍会正常弹出。

## 常见问题

**① 面板提示「连不上同步服务（检查网络/代理）」**
表示浏览器无法连接同步服务器（地址写在脚本顶部，自建后端参见文末附录）。多数情况下是网络原因，并非脚本故障。
- 已有代理或加速工具 → 开启后，脚本会自动使用系统代理
- 没有 → 先刷新页面；仍无效则参见文末[附录](#附录自己搭一个后端可选)，自行搭建并替换地址即可恢复。

**② 右下角没有圆形按钮？**
- 多数情况是**尚未在该网站上"匹配"**（返回第三步）。
- 另外，**未进入房间时页面本就不显示圆形按钮** —— 此时通过 **Tampermonkey 菜单 →「打开一起看」** 打开面板。
- 以上均无效时，刷新页面。

**③ 面板提示「同步正在另一个标签进行」？**
属正常现象 —— 同一浏览器中**只会有一个标签页在同步**（避免多个标签页相互冲突、来回拖动进度）。
脚本**不会**自行选择标签页进行同步：若要改为由**当前**标签页同步，点击面板中的 **「同步当前视频」**，
另一个标签页会自动停止。

> 打开新标签页**不会**抢走同步 —— 新标签页只显示房间，等待你点击按钮。
> 唯一的例外是点击了 **「跳转到一起看的视频」**：新开的标签页即为目标标签页，会直接接管同步。

**④ 面板里看不到成员 / 数据不动？**
等待数秒即可 —— 未在同步的标签页每 5 秒刷新一次成员列表。

**⑤ 我和朋友差一点进度？**
正常误差在 **0.3 秒**以内。如果房主网络卡顿（缓冲），全房间会自动暂停等待，房主可点击「**不等了，继续播放**」继续。

**⑥ 全屏的时候看不到提示？**
全屏时只保留右上角的**气泡提示**。
若某个网站将播放器本身（`<video>`）全屏，浏览器不允许任何内容叠加在其上，此情况无法避免（浏览器限制）。

**⑦ 想彻底不要了？**
Tampermonkey 管理面板 → 删除「一起看 · 视频同步」这一行 → 页面立即恢复原样。

**⑧ 朋友也需要装吗？**
需要。在安装页点击 **「复制安装地址」**，将链接发给对方，对方打开后安装即可。
后端地址已写入脚本，双方会自动连接到同一服务器、同一个房间。

**⑨ 控制台提示「页面上已有 N 个一起看面板」？**
说明同一浏览器中安装了**不止一份**脚本 —— 多份脚本会同时运行，彼此都认为自己负责同步，
从而出现「多个标签页同时同步 / 进度来回跳动 / 反复提示跳转」等异常现象。
- 打开油猴管理面板，查看「一起看 · 视频同步」是否存在**多行**
- 仅保留**版本号最高**的一行，删除其余各行 → 刷新页面
- 判断依据：脚本启动时会在控制台打印 `[一起看] v版本号 后端 …`，**应仅出现一行**

## 附录：自己搭一个后端（可选）

> 适用场景：需要完全自行掌控，或"连不上同步服务"的问题无法通过代理解决。
> 需要基础的命令行操作能力；不了解也不影响正常使用。

1. 安装 **Node.js 22 或更高版本**：`https://nodejs.org/`（按默认选项依次下一步）
2. 打开命令行（Windows 搜索"PowerShell"）：
   ```bash
   npm install -g wrangler
   wrangler login
   ```
   浏览器会弹出 Cloudflare 登录页，登录并授权。
3. 在本项目目录中：
   ```bash
   cd worker
   cp wrangler.toml.example wrangler.toml
   wrangler d1 create watch_party
   ```
   将屏幕上打印的 `database_id = "..."` 整行填入刚生成的 `wrangler.toml`。
4. 建表并部署：
   ```bash
   wrangler d1 execute watch_party --remote --file=./schema.sql
   wrangler deploy
   ```
   最后一行会打印你的地址，形如 `https://xxxx.workers.dev`。
5. 返回脚本（Tampermonkey 中的那一份），找到顶部的两处：
   ```js
   // @connect      your-worker.example.workers.dev
   ```
   ```js
   workerUrlRemote: "https://your-worker.example.workers.dev",
   ```
   将两处都替换为第 4 步获得的地址（`@connect` 处仅填写主机名，不带 `https://`），按 `Ctrl + S` 保存。

> **房主与成员必须使用后端地址相同的脚本**，否则双方不会连接到同一个房间。
> 更详细的英文步骤见 `docs/SETUP.md`。

```
房主：创建房间 → 把房间码发给成员
成员：加入 → 视频不同则点击"跳转到一起看的视频"（跨站同内容时点击"强制同步"）
卡顿：全房间暂停等待，房主可点击"不等了"
连不上：开启代理，或自行搭建后端
不需要了：在 Tampermonkey 中删除脚本
```
